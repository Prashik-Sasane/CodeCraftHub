# Car Dealership Application

## Project Name
**Car Dealership Application**

## Project Overview
The Car Dealership Application is a full-stack web application that allows users to browse car dealerships, explore car makes and models, view dealership details, and submit customer reviews. It integrates a Django-based web application with a React frontend and an Express-Mongo application for dealership-related APIs.

The project demonstrates full-stack development, user authentication, database integration, REST API operations, sentiment analysis, and application deployment.

## Key Features

- **User Registration:** Register users with username, first name, last name, email, and password.
- **Login and Logout:** Authenticate users and manage their sessions.
- **Dealership Listing:** Display available dealerships on the home page.
- **Dealership Filtering:** Filter dealerships by state.
- **Dealership Details:** View individual dealership information and associated reviews.
- **Customer Reviews:** Submit and display reviews for dealerships.
- **Car Makes and Models:** Manage and display car makes and models.
- **Sentiment Analysis:** Analyze the sentiment of customer reviews.
- **REST APIs:** Retrieve dealership information and reviews using the Express-Mongo application.
- **About Us and Contact Us:** Provide application information and contact details.
- **CI/CD:** Use GitHub Actions to automate the configured workflow.
- **Deployment:** Deploy the Django application and verify its pages and functionality.

## Technology Stack

- **Frontend:** React, HTML, CSS, JavaScript
- **Web Framework:** Django
- **Backend API:** Express.js
- **Database:** MongoDB
- **API Communication:** REST APIs
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions
- **Deployment:** As configured for the project

## Application Components

### Django Web Application
Provides the user-facing dealership website, authentication, dealership listings, state-based filtering, dealership details, and review submission.

### Express-Mongo Application
Provides dealership and review API operations, including retrieving all dealerships, dealership details, and reviews for a selected dealer.

### Sentiment Analysis
Provides sentiment analysis functionality for customer reviews through the application's configured analyzer.

## Project Objectives

1. Develop a full-stack car dealership application.
2. Integrate frontend and backend components.
3. Implement user registration, login, and logout.
4. Retrieve dealership data and customer reviews through APIs.
5. Display car makes and models.
6. Implement customer review submission and sentiment analysis.
7. Configure CI/CD and deploy the application.
